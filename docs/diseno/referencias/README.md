# Referencias visuales

La guía pide guardar aquí las capturas de la pantalla de referencia. Toma estas imágenes del **prototipo** (`documentos/inmocheck-prototipo/index.html`) y de la **app** para mostrar que el diseño se respetó:

| Archivo | Qué capturar |
|---|---|
| `sistema-de-diseno.png` | `3-sistema-y-compartidas/sistema-de-diseno.html` completo |
| `realizar-prototipo-390.png` | `2-inspector/inspeccion-realizar.html` a 390 px de ancho |
| `realizar-app-390.png` | `/dashboard/inspecciones/[id]/realizar` en la app a 390 px |
| `inmuebles-prototipo-1280.png` | `1-administrador/inmuebles.html` a 1280 px |
| `inmuebles-app-1280.png` | `/dashboard/inmuebles` en la app a 1280 px |

En Chrome: F12 → ícono de celular (Ctrl+Shift+M) → ancho 390 → menú ⋮ → "Capturar pantalla completa".
